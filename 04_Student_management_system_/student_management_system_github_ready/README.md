# 🎓 Student Management System — Python Mini Project

A beginner-friendly **Python mini project** that demonstrates how to build a menu-driven Student Management System using Python and CSV file handling.

## ⭐ Features

- ➕ Add student
- 📋 View all students
- 🔍 Search student
- ✏️ Update student
- 🗑️ Delete student
- 🥇 Find topper
- 📊 Calculate percentage automatically
- 🎯 Calculate grade automatically
- 💾 Store records in CSV
- 🔄 Load records when the program starts
- ⚠️ Input validation
- 🧪 Automated tests

## 🛠️ Concepts Used

This project is useful for learning:

- Variables

- `while` loops

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/student-management-system.git
cd student-management-system
```

### 2. Run the application

No external packages are required.

```bash
python main.py
```

### 3. Run tests

Install pytest if needed:

```bash
pip install pytest
```

Then:

```bash
pytest -q
```
