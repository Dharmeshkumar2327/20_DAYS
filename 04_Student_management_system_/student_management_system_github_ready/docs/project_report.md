# Student Management System — Project Report

## Objective
Build a menu-driven Python application for managing student records.

## Features
Add, view, search, update, delete students; calculate percentage and grade; find topper; persist records using CSV.

## Concepts
Functions, loops, conditions, lists, dictionaries, CSV file handling, exception handling and basic testing.

## Future Scope
SQLite/MySQL database, Tkinter GUI, attendance, authentication, Excel/PDF reports and a web interface.
