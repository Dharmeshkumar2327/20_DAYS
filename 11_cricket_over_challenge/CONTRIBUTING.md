# Contributing

Suggestions and improvements are welcome.

1. Fork the repository.
2. Create a branch for your change.
3. Keep code beginner-friendly and add comments where they clarify the logic.
4. Run the tests before submitting:

   ```bash
   python -m unittest discover -s tests -v
   ```

5. Open a pull request explaining what changed and how you tested it.

For larger changes, open an issue first to discuss the idea.
